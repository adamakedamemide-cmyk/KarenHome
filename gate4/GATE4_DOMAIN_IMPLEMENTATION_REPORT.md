# GATE4_DOMAIN_IMPLEMENTATION_REPORT — Karen Home

Mandate §3 requires, for each bounded context: Entity, Value Objects, Repository, Command, Query, Application Service, Policy, Domain Event, Integration Event, Error Codes, Permissions, Transaction Boundary. The frozen Database Contract (base 99 tables + 0031/0032-0034) defines the entity storage; TypeScript code follows `Database Contract → Domain → Application → Repository → API → Events → Workers` (§2). No controller runs business logic directly; no service mutates another domain's tables without its repository boundary.

## Notes

- Every domain owns its error codes via the shared `DomainError` (§18) — codes, statuses and localization keys are centralized in `@platform/contracts` + `error-catalog` (en/ru).
- Value Objects are modeled as validated primitives (decimal strings for money/areas, E.164, citext email, locale regex, currency char(3)) per the frozen contract's numeric-as-string convention — a deliberate, tested decision.
- Transaction boundaries: repositories own transactions; cross-repo participation goes through the `QueryExecutor` seam; workers use job-level idempotency + dedup keys instead of distributed transactions.
