# Error Model

Error codes are stable API contracts. Messages are human-readable and may be localized; clients must branch on `code`.

## Identity
- `AUTH_INVALID_CREDENTIALS`
- `AUTH_SESSION_REVOKED`
- `AUTH_VERIFICATION_REQUIRED`

## Authorization
- `FORBIDDEN`
- `ORG_SCOPE_REQUIRED`
- `RESOURCE_NOT_OWNED`

## Listings
- `LISTING_NOT_PUBLISHABLE`
- `LISTING_STATE_CONFLICT`
- `LISTING_PRICE_OVERLAP`
- `LISTING_MEDIA_REQUIRED`
- `LISTING_COVER_REQUIRED`
- `LISTING_DUPLICATE_SUSPECTED`

## Properties
- `PROPERTY_SUBTYPE_MISMATCH`
- `PROPERTY_OWNERSHIP_NOT_BALANCED`
- `CADASTRAL_NUMBER_CONFLICT`

## Projects
- `PROJECT_UNIT_SCOPE_CONFLICT`
- `DEVELOPER_ORGANIZATION_REQUIRED`

## Payments
- `IDEMPOTENCY_KEY_REUSED_WITH_DIFFERENT_PAYLOAD`
- `PAYMENT_CURRENCY_MISMATCH`
- `ORDER_STATE_CONFLICT`
- `REFUND_NOT_ALLOWED`
- `LEDGER_NOT_BALANCED`

## Rental
- `LEASE_OVERLAP`
- `RENT_SCHEDULE_CURRENCY_MISMATCH`
- `RENT_PAYMENT_CURRENCY_MISMATCH`
- `LEASE_STATE_CONFLICT`

## Generic
- `VALIDATION_FAILED`
- `RESOURCE_NOT_FOUND`
- `CONFLICT`
- `RATE_LIMITED`
- `INTERNAL_ERROR`
- `DEPENDENCY_UNAVAILABLE`
